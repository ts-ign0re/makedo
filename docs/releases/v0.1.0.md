The first public release.

makedo is a coding agent built on one idea: cheap models can work on serious codebases when they get a knowledge layer, discipline and self-checking. It is a single Rust binary that runs in your terminal or in its own macOS window.

### What is in it

- **A project wiki.** A versioned knowledge graph in `.makedo/wiki/`, kept in git. A cheap model fills it in, and the agent searches it before it greps.
- **Any model.** Anthropic, OpenAI, Gemini, DeepSeek, Qwen, OpenRouter, local Ollama, your own OpenAI-compatible servers, or a ChatGPT subscription.
- **A verification gate.** After a turn that changes code, makedo runs your checks and hands failures back to the model until they pass.
- **Project memory.** SQLite with full-text and semantic search, shared by all worktrees.
- **Subagents and worktrees.** Read-only research, and edits in an isolated working copy.
- **MCP both ways.** Servers connect through two meta-tools; `makedo mcp-serve` exposes the wiki and memory to other agents.
- **Built-in skills.** Ponytail, Open Code Review and Heavy ship inside the binary.
- **A macOS window (prototype).** The same interface as an app with a Dock icon; build it with `scripts/bundle-macos.sh`.

### In numbers

On the project's own tasks, a feature with tests and self-checking cost $0.13 on deepseek-v4-pro with a warmed-up wiki, against $3.5–5.2 on sonnet. The full tables and their limits are in [docs/BENCHMARKS.md](https://github.com/ts-ign0re/makedo/blob/main/docs/BENCHMARKS.md).
