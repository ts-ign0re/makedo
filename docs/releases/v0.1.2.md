makedo now ships TRIZ and Lean, two built-in skills that are always on: the agent looks for the cheapest change before it writes anything, and keeps the work itself cheap.

### What is new

- **TRIZ.** Before a change that adds a file, entity, endpoint or dependency, the agent lists cheaper candidates, from "nothing to build" to "a config knob", rejects each with a rule from the project's own files, and names the binding constraint. Every answer ends with one `optimality:` line.
- **Lean.** Lean-manufacturing rules for the agent's process: the eight wastes, check the code instead of remembering it, stop on a failing check, ask why five times before fixing a symptom.
- **A switch.** Both skills are in the system prompt by default, about 2,000 tokens. `[skills] triz = false` in `config.toml` returns them to on-demand loading through `skill_search` and `skill_load`.
